# Chimenea Limpia

Juego web para celular: ayudá a Moncho, el deshollinador de SolesUY, a sacar el hollín de estufas y chimeneas para que Papá Noel llegue impecable a dejar los regalos.

- Todo el juego está en `index.html` (HTML5 canvas, sin dependencias).
- Para publicarlo en Vercel: importá este repositorio en vercel.com/new. No necesita build ni configuración: es un sitio estático.
- Más info y limpieza de estufas en https://solesuy.com
